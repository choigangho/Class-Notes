1. 클래스, 오브젝트

- pc
  cpu - memory - board - ssd

  cpu가 ssd에 접근해서 프로그램을 실행하면 성능이 ssd에 종속됨 
  -> cpu가 ssd에 접근 못하도록 설계됨

  대규모 프로그램 -> 용량이 커서 전부 메모리에 올라갈 수 없음
  -> 자바에서 대규모 코드를 메모리에 올릴 수 있도록 소분 기능을 제공
 
  그 소분 최소 단위가 즉 메모리에 올리는 기본 단위가 class !!!!

- class
  class Test {}      // 이런 클래스가 있다고 가정
  new Test()        // 해당 클래스를 메모리에 올려라 !!!!

- 객체
  메모리에 올라간 클래스
  ex) Test t = new Test();	// t 가 객체
