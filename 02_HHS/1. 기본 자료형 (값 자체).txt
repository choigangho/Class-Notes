1. 기본 자료형 (값 자체)
 
1) 정수형 int
byte(용량 1byte) - short(2byte) - int(4byte) - long(8byte)

byte  b      = 10; (1byte: -128 ~ 127)
byte  result = b + 1; (X) -> java의 컴파일이 b의 값의 범위를 모름 -> b가 127이면 용량 초과
short result = b + 1; (X) -> 같은 이유
int   result = b + 1; (O)
long  result = b + 1; (int 용량이 부족할 때)
long bigNumber = 3000000000000L; (리터럴 명시)


2) 실수형 double
float  f = 0.1; (X)
double d = 0.1; (O) -> 명시(f) 안하면 default double
float  f = 0.1f; (리터럴 명시)


3) 문자형
char c   = 'A';
char c2  = 65; -> ASCII CODE
string s = "ABC";


4) Boolean 형
boolean boo = true;
boo = false;


2. 배열 array (주소 값)
같은 타입에 값을 여러개 저장할 수 있는 공간
int[] x = {10, 20, 30};

int[] y = new int[3];
        y[0] = 10;
        y[1] = 20;
        y[2] = 30;

int[] k = new int[]{10, 20, 30};

다차원 배열, 다차원 배열 동적 할당은 생략

배열은 실무에서 잘 안쓰임 다른 자료형이 있음 (딕셔너리?)

3. 자바에서 "="
- 기본자료형 제외하면 주소 값이 할당
- 기본자료형은 값 자체
Q: string s = "ABC" 는 값이 할당 된거냐 주소값이 할당 된거냐
A: 주소값 -> 기본자료형이 아니니까
String 은 java.lang 패키지에 정의된 참조형(Reference type) 클래스
Q: 그럼 왜 String s = new String("ABC"); // 표준적인 클래스 인스턴스 생성 방식

A: 자주 사용해서 걍 생략가능하게 함.
