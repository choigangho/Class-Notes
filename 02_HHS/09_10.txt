	- JDK (java development kit): 1.5 1.8 *17*(실무에서 실제 사용중) 21 (LTS) (JRE 포함)

	- IDE intellij

2. 자바 기본적 특징
- 자바 소스코드 기본 특징
	1) 자바 소스코드 확장자는 xxx.java 로 끝남 

	2) 자바 소스코드 파일명은 소스코드 내의 클래스 명과 동일
	   ex) public class HelloJava {} -> HelloJava.java

	3) 자바 소스코드는 class가 먼저 만들어지고 내부에 코드를 만들어 주어야 함. class가 없는 자바 소스코드는 존재 불가

	4) 자바 소스코드 컴파일 후 결과물로 xxx.class 파일이 만들어짐
	   ex) msg 좀 쳐서 xxx.class는 실행 파일이라고 생각해도 됨
	        public class HelloJava {} -> HelloJava.java
		컴파일 후 -> HelloJava.class 파일이 생성

- JVM (Java Virtual Machine)
	- xxx.class 파일은 특정 운영체제에서 실행가능한 파일이 아니라 JVM에서 실행 가능한 파일이다.

	- 운영체제마다 전용 JVM이 존재 -> 코드 실행이 운영체제에 종속되지않음 -> 어떤 운영체제라도 코드 정상 실행 (JVM -> JRE)

	- 특정 운영체제에서만 동작하는 기능을 지원하지않음 -> JVM은 모든 운영체제에 일관되어야 함  
	  한계) 윈도우에서는 되지만 리눅스에서는 안되는 게임 기능 지원 안됨 -> 자바로 게임 제작 안하는 이유

3. 기본 자료형
	- 변수: 저장 공간
	  공간 효율을 위해 변수 초기화 시에 변수 값의 저장공간 범위를 정적(파이썬은 동적)으로 정해주어야 함 
	- 자바 기본 자료형
		1) 정수형 : byte(1byte) - short(2byte) - int - long
		2) 실수형 : float - double
		3) 문자형 : char
		4) boolean형 : boolean
